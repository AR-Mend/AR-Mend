# Human brain model

Supplied by the user as human-brain.zip. Original archive entry: source/Rotten Brain.glb. No author attribution or license document was present in the archive. No license is inferred.

The webpage uses human-brain.glb, a compatibility adaptation of that asset. Its legacy KHR_materials_pbrSpecularGlossiness material is converted to core glTF metallic/roughness shading using the original embedded diffuse and normal textures. Geometry, UVs, and node transforms are preserved. The material uses a fixed roughness of 0.65 rather than the legacy gloss texture. Lighting and scene materials are adjusted at runtime for the site's viewing modes. The model is centered and scaled automatically.

The archive's separate textures are redundant for the self-contained GLB and are not required by the website. Keep any original licensing documentation with this file if supplied later.
